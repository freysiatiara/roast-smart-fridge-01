## The entry

> My doorbell camera has seen me in my pyjamas more often than my own mother has — and unlike her, it keeps the footage.

`main.py` (Python standard library only) writes that single line, with no
trailing newline, to `entry.txt` in the output directory. See `CANDIDATES.md`
for the candidate panel and the head-to-head reasoning behind the pick.

## Usage

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```

The output directory is resolved from `MAKEFUN_OUTPUT_DIR`, then `OUTPUT_DIR`,
then `ENTRY_OUTPUT`, defaulting to `/output`.
